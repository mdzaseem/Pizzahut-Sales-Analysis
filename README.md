# Pizza Sales Analysis using SQL

## About the Project

Hi! This is one of my SQL projects, where I worked on pizza sales data to understand how the business was performing.

I wanted to practice SQL on a dataset instead of just learning queries from tutorials. So, I used MySQL to explore the data, calculate sales and revenue, and find answers to different business questions.

I worked with four tables: orders, order details, pizzas, and pizza types. By joining these tables and writing SQL queries, I tried to understand which pizzas sold the most, which category generated more revenue, and when most orders were placed.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## What I Worked On

I divided the analysis into three parts.

**Basic Analysis**
- Counted the total number of orders.
- Calculated total sales revenue.
- Found the highest-priced pizza.
- Checked the most frequently appearing pizza size.
- Identified the top 5 pizza types by quantity sold.

**Intermediate Analysis**
- Compared the quantity sold across pizza categories.
- Analyzed orders by hour.
- Counted the number of pizza varieties in each category.
- Calculated the average number of pizzas sold per day.
- Found the top 3 pizza types by revenue.

**Advanced Analysis**
- Calculated each pizza category's percentage contribution to total revenue.
- Used a window function to calculate cumulative revenue over time.
- Ranked pizza types by revenue within their categories.

In total, I worked on 13 SQL questions, starting with basic queries and moving towards more advanced concepts.

## Key Findings

Here are a few results I found while working on the project:

- Total orders: **21,350**
- Total revenue: **$817,860.05**
- Highest-priced pizza: **The Greek Pizza ($35.95)**
- Top-selling pizza by quantity: **Classic Deluxe (2,453 pizzas)**
- Highest-revenue pizza category: **Classic (26.91% of total revenue)**
- Highest-revenue pizza type: **Thai Chicken Pizza ($43,434.25)**

These findings gave me a better understanding of how sales data can be used to answer business questions.
